*******
1. 브랜치는 독립적인 작업 공간을 만드는 것브랜치
#생성: git branch [브랜치명] (예: git branch backend)
#브랜치 목록 확인: git branch (현재 위치한 브랜치는 *로 표시됨)
#브랜치 이동: git switch [브랜치명] (또는 git checkout [브랜치명])

특정 브랜치에서 파일을 만들고 커밋(add & commit)을 하지 않으면 다른 브랜치로 이동해도 그 파일이 계속 보입니다.
Git이 관리하기 전 단계이기 때문입니다. 반드시 해당 브랜치에서 커밋을 완료해야 해당 브랜치에 귀속

***원격 저장소 반영: git push -u origin [브랜치명]을 해야 깃허브 웹사이트에서도 해당 브랜치와 작업 내용이 나타납니다.

로그 확인: git log --graph --oneline
이 명령어를 쓰면 현재 브랜치의 진행 상황을 한눈에 볼 수 있습니다. iot 브랜치에서는 iot 작업만 보이고, main에서는 아직 합치기 전이라면 다른 브랜치의 작업이 보이지 않는 것이 정상입니다.
