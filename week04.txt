임의의 파일 생성
git add 파일명
git commit -m "쓰고 싶은 메시지"
초기화 됐기 때문에 email 사용자필명 등록 필요
그리고 다시 커밋
git remote add origin 본인원격리포지토리주소
git remote -v 등록 확인
git push -u origin main (원격 리포지토리에 업로드 및 동기화)
현재 실습실 컴퓨터는 기본 브라우저가 edge브라우저 인증창 뜨면
edge브라우저에 뜬 주소를 잘라내기해서 크롬에서 새 탭 띄우고 붙여넣기 인증
git push (u 옵션 때문에 한번만 git push -u origin main 해주면 그 다음 부터는 git push만)
