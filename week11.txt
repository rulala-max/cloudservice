[vi / vim]

vi week11.txt
i                  : 입력모드
Esc                : 명령모드로 나가기

dd                 : 현재 한 줄 삭제
x                  : 한 글자 삭제
u                  : 실행 취소(undo)

:wq                : 저장 후 종료
:q!                : 저장 안 하고 강제 종료

----------------------------

[파일 생성 / 내용 확인]

touch test.txt     : 빈 파일 생성

cat week11.txt     : 파일 내용 출력
vi week11.txt      : vi로 파일 열기
nano 3.txt         : nano 편집기로 열기

echo "456" >> 4.txt
: 파일 끝에 내용 추가

[Git 브랜치]

git branch temp01
: 브랜치 생성만

git switch temp01
: 해당 브랜치로 이동

----------------------------

[브랜치 생성 + 이동 한 번에]

git checkout -b temp01

또는

git switch -c temp01

※ 여기까지는 로컬 브랜치만 생성됨

git branch
: 브랜치 목록 확인

----------------------------

[브랜치 원격 업로드]

git add .
git commit -m "메시지"

처음 push:
git push -u origin temp01

이후:
git push

※ push 해야 GitHub(원격)에도 브랜치 생성됨

----------------------------

[merge]

main 브랜치에서는
다른 브랜치 파일이 아직 안 보임

main에서 merge 해야 합쳐짐

git merge temp01
git push

----------------------------

[충돌(conflict)]

같은 파일을 각각 다른 브랜치에서 수정하면 충돌 발생

예시:
git merge temp03

결과:
CONFLICT (content): Merge conflict in test.txt

해결 방법:
1. 파일 직접 수정
2. vi에서 수정

vi test.txt
화살표 이동
dd : 줄 삭제

수정 후:

git status
git add .
git commit -m "conflict resolve"
git push

----------------------------
